# Sip & Play — Commercial Kitchen Solutions

An ultra-premium, monochromatic digital experience and 500-product equipment catalogue for world-class hospitality groups, hotels, and commercial culinary operations.

## Features
- **Monochromatic Luxury Aesthetic**: Architectural typography (Cinzel, Cormorant Garamond, Inter) with a refined black-and-white editorial aesthetic.
- **500-Product Commercial Catalogue**: Complete searchable dataset with live multi-filtering across 8 disciplines, manufacturers, and utility specs.
- **Instant Search & High-Performance Pagination**: 0ms lag across 500 items with smart ellipsis pagination.
- **Interactive Technical Spec Modal**: Detailed CAD/MEP-style specifications, utility connection loads, and dimension callouts.
- **Specification Schedule Builder**: Floating RFQ tray allowing clients to build custom equipment schedules and submit batch quote requests.
- **Fully Responsive**: Calibrated layout for desktop, tablet, and mobile displays.

## Tech Stack
- HTML5 / CSS3 (Vanilla design system)
- JavaScript (Client-side search, filtering, and interaction engine)

## Setup & Running Locally
Simply serve the files with any static server:
```bash
python -m http.server 8085
```
Open `http://localhost:8085` in your browser.
